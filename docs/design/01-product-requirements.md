# 01 — 产品需求规格书

## 1. 用户体系与角色分层

SaaS 平台有两个维度的用户：**平台侧** 和 **租户侧**。

```
┌─ 平台侧（运营团队）────────────────────────────┐
│  平台超管        管理所有租户、配额、计费         │
│  平台运营        查看租户数据、处理工单           │
└────────────────────────────────────────────────┘

┌─ 租户侧（企业客户）────────────────────────────┐
│  租户管理员      企业注册人，管理本企业所有功能    │
│  部门主管        审批流程、查看部门数据           │
│  普通员工        发起流程、处理任务              │
│  运营专员        管理公众号内容/粉丝             │
└────────────────────────────────────────────────┘
```

**核心规则：**
- 平台侧用户不属于任何租户，拥有跨租户视角
- 租户管理员是租户内的最高权限，但看不到其他租户
- 同一个手机号/邮箱不能在两个租户中注册（防混乱）

## 2. 租户管理模块（平台侧独有）

这是传统管理系统没有的模块，是 SaaS 的核心。

### 2.1 租户生命周期

```
注册 → 试用(15天) → 付费激活 → 正常运行 → 到期提醒 → 续费/冻结 → (可选)注销
```

| 编号 | 功能 | 说明 |
|------|------|------|
| T-01 | 租户注册 | 企业名称+管理员手机+验证码，自动创建租户+管理员账号+默认角色+默认菜单 |
| T-02 | 租户列表 | 平台超管查看所有租户，含状态/到期时间/用户数/存储用量 |
| T-03 | 租户详情 | 查看租户基本信息、配额使用情况、操作日志 |
| T-04 | 冻结/解冻 | 冻结后租户所有用户无法登录，数据保留 |
| T-05 | 配额管理 | 设置租户的用户上限/流程数上限/公众号绑定数上限/存储空间 |
| T-06 | 套餐管理 | 定义套餐（免费版/基础版/专业版），不同套餐不同配额 |
| T-07 | 租户注销 | 软删除，数据保留 90 天后物理清理 |

### 2.2 套餐设计

| 套餐 | 价格 | 用户数 | 流程定义 | 公众号 | 存储 |
|------|------|--------|---------|--------|------|
| 免费版 | 0 | 10 人 | 5 个 | 1 个 | 1 GB |
| 基础版 | 299/月 | 50 人 | 20 个 | 3 个 | 10 GB |
| 专业版 | 999/月 | 200 人 | 不限 | 10 个 | 100 GB |
| 旗舰版 | 按需 | 不限 | 不限 | 不限 | 不限 |

## 3. 权限管理模块（租户侧）

### 3.1 租户开通时的初始化

租户注册成功后，系统自动创建：

```
1. 一个管理员账号（注册人）
2. 一个"管理员"角色（role_level=1, data_scope=1）
3. 一个根部门（企业名称）
4. 一套默认菜单（全部可见）
```

管理员登录后可以：创建子部门 → 创建角色 → 分配权限 → 邀请成员

### 3.2 用户管理

| 编号 | 功能 | 说明 |
|------|------|------|
| U-01 | 成员列表 | 分页查询本租户用户，按部门树左侧筛选 |
| U-02 | 邀请成员 | 输入手机号/邮箱，发送邀请链接，受邀人设置密码后加入 |
| U-03 | 直接添加 | 管理员填写信息+初始密码，直接创建 |
| U-04 | 编辑成员 | 修改信息/部门/角色 |
| U-05 | 移除成员 | 逻辑删除，该用户在本租户内失效 |
| U-06 | 启用/禁用 | 禁用后立即失效 |
| U-07 | 重置密码 | 管理员可重置 |
| U-08 | 个人设置 | 用户自行修改昵称/头像/密码 |
| U-09 | 配额提示 | 接近用户数上限时提示升级套餐 |

**与单租户的区别：**
- 用户属于一个租户，不能跨租户
- 用户数受套餐配额限制
- "邀请制" 替代"批量导入"（SaaS 更常见的模式）

### 3.3 角色管理

| 编号 | 功能 | 说明 |
|------|------|------|
| R-01 | 角色列表 | 本租户的角色列表 |
| R-02 | 新增角色 | 角色名称+编码+数据范围 |
| R-03 | 编辑角色 | - |
| R-04 | 删除角色 | 有用户绑定时不可删除 |
| R-05 | 分配权限 | 树形勾选菜单+按钮，但只能勾选本套餐已开通的功能 |
| R-06 | 数据范围 | 全部/本部门/本部门及下级/仅本人/自定义 |

**与单租户的区别：**
- 角色的可选权限范围受套餐约束（免费版看不到工作流菜单）
- 初始"管理员"角色不可删除

### 3.4 部门管理

和单租户设计相同，但限定在租户范围内。每个租户有独立的部门树。

### 3.5 菜单管理

**关键设计决策：菜单是平台级还是租户级？**

```
方案 A: 平台统一管理菜单模板，租户不可自定义菜单
方案 B: 每个租户可以自定义自己的菜单结构

推荐方案 A。理由：
- SaaS 产品的功能入口应该统一，降低维护和客服成本
- 通过"套餐控制可见菜单"实现差异化，而不是让租户自己改菜单
- 租户管理员只需要给角色分配权限，不需要操心菜单怎么摆
```

所以菜单表是**平台级**的（不带 tenant_id），角色-菜单关联是**租户级**的（带 tenant_id）。

## 4. 流程引擎模块（租户侧）

### 4.1 流程设计

| 编号 | 功能 | 说明 |
|------|------|------|
| WD-01 | 流程模板 | 平台提供预置模板（请假/报销/合同），租户可直接用 |
| WD-02 | 自定义流程 | 租户管理员可用 BPMN 设计器创建自定义流程 |
| WD-03 | 流程部署 | 设计完成后部署为可用流程 |
| WD-04 | 版本管理 | 新版本部署后，运行中的实例继续用旧版本 |
| WD-05 | 挂起/激活 | 挂起后不可发起新实例 |
| WD-06 | 节点配置 | 配置每个审批节点的审批人规则和审批模式 |
| WD-07 | 配额提示 | 流程定义数接近上限时提示升级 |

**与单租户的区别：**
- 平台提供预置流程模板（租户可一键启用）
- 流程定义数量受套餐配额限制
- 审批人只能选本租户内的用户/角色/部门

### 4.2 发起与审批

| 编号 | 功能 | 说明 |
|------|------|------|
| WI-01 | 发起入口 | 展示当前租户可用的流程列表（卡片/列表视图） |
| WI-02 | 填写表单 | 每个流程关联一个表单（URL 外链或内嵌 JSON 表单） |
| WI-03 | 我的待办 | 需要我处理的任务 |
| WI-04 | 我的已办 | 我已处理的任务 |
| WI-05 | 我发起的 | 我发起的流程及状态 |
| WI-06 | 审批操作 | 通过/驳回/转办/委派/加签 + 审批意见 |
| WI-07 | 抄送我的 | 别人抄送给我的流程 |
| WI-08 | 催办 | 向当前审批人发催办通知 |
| WI-09 | 撤回 | 首个审批节点未处理前可撤回 |
| WI-10 | 流程详情 | 流程图高亮 + 审批时间线 |

### 4.3 流程监控（管理员视角）

| 编号 | 功能 | 说明 |
|------|------|------|
| WM-01 | 实例监控 | 本租户所有运行中的流程 |
| WM-02 | 强制终止 | 管理员终止异常流程 |
| WM-03 | 审批统计 | 平均耗时、超时率、各流程使用量 |

## 5. 微信公众号模块（租户侧）

### 5.1 账号管理

| 编号 | 功能 | 说明 |
|------|------|------|
| WA-01 | 绑定公众号 | 录入 AppID + AppSecret，调微信接口验证 |
| WA-02 | 账号列表 | 本租户绑定的所有公众号 |
| WA-03 | 切换公众号 | 页面顶部下拉切换当前操作的公众号 |
| WA-04 | 解绑 | 解绑后清理缓存，数据保留 |
| WA-05 | 配额限制 | 绑定数量受套餐限制 |

### 5.2 内容管理

| 编号 | 功能 | 说明 |
|------|------|------|
| WC-01 | 素材库 | 图片/语音/视频/缩略图分类管理 |
| WC-02 | 上传素材 | 上传到本地存储 + 同步到微信服务器 |
| WC-03 | 图文编辑 | 富文本编辑器，支持从素材库插入图片 |
| WC-04 | 图文发布 | 草稿 → 预览 → 发布 |
| WC-05 | 图文列表 | 按状态筛选（草稿/已发布/已下线） |

### 5.3 粉丝运营

| 编号 | 功能 | 说明 |
|------|------|------|
| WF-01 | 粉丝列表 | 分页展示，按标签/状态筛选 |
| WF-02 | 粉丝同步 | 从微信服务器全量同步 |
| WF-03 | 标签管理 | 创建/编辑/删除标签，给粉丝打标签 |
| WF-04 | 黑名单 | 拉黑/取消拉黑 |
| WF-05 | 自动回复 | 关注回复/关键词回复/默认回复 |

### 5.4 菜单配置

| 编号 | 功能 | 说明 |
|------|------|------|
| WE-01 | 可视化编辑 | 拖拽式编辑公众号底部菜单 |
| WE-02 | 一键发布 | 同步到微信服务器 |

### 5.5 数据看板

| 编号 | 功能 | 说明 |
|------|------|------|
| WD-01 | 粉丝趋势 | 新增/取关/净增折线图 |
| WD-02 | 图文排行 | 按阅读/分享/收藏排行 |

## 6. 平台运营后台（平台侧独有）

这是给平台运营团队用的独立后台（独立前端入口，不和租户端混在一起）。

| 编号 | 功能 | 说明 |
|------|------|------|
| P-01 | 租户管理 | 创建/冻结/解冻/注销租户 |
| P-02 | 套餐管理 | 定义和调整套餐内容 |
| P-03 | 全局统计 | 租户数、用户总数、日活、流程总量 |
| P-04 | 系统公告 | 向所有/指定租户推送公告 |
| P-05 | 平台配置 | 全局开关、默认套餐、试用天数等 |

## 7. 通知体系

```
┌───────────── 触发源 ─────────────────────────────────┐
│                                                       │
│  待办到达 / 审批结果 / 催办 / 抄送 / 套餐到期 / 系统公告  │
│                                                       │
└──────────────────────┬────────────────────────────────┘
                       │
         ┌─────────────┼─────────────┐
         │             │             │
    站内消息        邮件通知      IM Webhook
   (必做 P0)      (P1)         (P2: 飞书/钉钉)
```

每个租户可以自行配置启用哪些通知渠道。
