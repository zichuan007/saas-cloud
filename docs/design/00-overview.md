# AI Cloud Plus V2 — SaaS 企业管理平台

> 产品全局设计文档入口

## 产品定位

面向中小企业的 SaaS 一站式管理平台。企业（租户）自助注册后，即可获得完整的
组织权限管理、流程审批、微信公众号运营能力。平台方管理所有租户的生命周期、配额和计费。

## 核心差异点

与传统单租户管理系统的本质区别：

```
传统管理系统                          SaaS 多租户平台
──────────                          ─────────────
一套系统给一家公司用                    一套系统给 N 家公司用
超级管理员 = 系统最高权限               平台管理员 ≠ 租户管理员
没有"开通/关闭"概念                    租户有生命周期（试用→付费→到期→冻结）
所有数据天然隔离（只有一家）             必须保证 A 公司绝对看不到 B 公司数据
部署一套就行                          一套代码服务所有租户，运维成本摊薄
```
